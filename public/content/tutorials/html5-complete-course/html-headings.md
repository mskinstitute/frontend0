# HTML Headings (`<h1>` to `<h6>`)

Headings define the structural hierarchy and outline of an HTML document. Search engines like Google use headings to understand the main topic and subtopics of your web pages.

---

# The Six Heading Levels

HTML provides six levels of section headings:

```html
<h1>Main Page Heading (h1 - Most Important)</h1>
<h2>Section Title (h2)</h2>
<h3>Sub-section Title (h3)</h3>
<h4>Minor Heading (h4)</h4>
<h5>Sub-minor Heading (h5)</h5>
<h6>Lowest Level Heading (h6 - Least Important)</h6>
```

---

# Essential SEO & Accessibility Rules for Headings

1. **Exactly One `<h1>` Per Page:**
   Always use exactly one `<h1>` per document. It acts as the primary title of the page for search engine ranking.
2. **Never Skip Levels:**
   Always follow a clean outline. Do not jump from `<h2>` directly down to `<h4>`.
3. **Never Use Headings Just for Large Text:**
   If you want large or bold text for a promotional banner, use a paragraph or div styled with CSS—never a heading tag.

# Practice Quiz

### 1. Which heading tag represents the highest importance?
- A) `<h0>`
- B) `<h6>`
- C) `<h1>`
- D) `<head>`
**Answer:** C
**Explanation:** `<h1>` is the top-level heading.
