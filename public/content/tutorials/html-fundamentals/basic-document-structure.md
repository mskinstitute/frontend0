# Basic Document Structure in HTML5

Every modern web page follows a standardized skeleton consisting of `<!DOCTYPE html>`, `<html>`, `<head>`, and `<body>`.

```html
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First HTML Page | MSK Institute</title>
  </head>
  <body>
    <h1>Welcome to MSK Institute</h1>
    <p>Hands-on coding education in Shikohabad.</p>
  </body>
</html>
```

### The Essential Tags:
1. `<!DOCTYPE html>`: Declares modern HTML5 Standards Mode.
2. `<html lang="en">`: Root container declaring page language.
3. `<head>`: Invisible metadata, title, viewport, and stylesheet links.
4. `<body>`: Visible user content.
