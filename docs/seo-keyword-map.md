# MSK Institute — Keyword-to-Page Map

**Website:** `https://www.mskinstitute.in`  
**Core Strategy:** Single Intent = Single Canonical URL (Zero Self-Competition)  
**Status:** Active Production Blueprint  

---

## 1. Architectural Principle: 1 Primary Intent = 1 Canonical URL

To eliminate internal keyword cannibalization, every high-value search intent is mapped to exactly one primary ranking URL. Supporting pages (blogs, tutorials, cheatsheets) target specific sub-intents (e.g. "how to", "interview questions", "syntax cheatsheet") and pass topical link equity back to the commercial course hub.

```text
       [ Commercial / Course Intent ] ──► /courses/[slug]
       [ Career / Roadmap Intent ]    ──► /blogs/[slug]
       [ Educational How-To Intent ]  ──► /tutorials/[slug]/[topic]
       [ Reference / Syntax Intent ]  ──► /study-material (Cheatsheet)
       [ Live Cohort Intent ]         ──► /live-batches/[id]
       [ Local Intent ]               ──► /contact or / (Homepage)
```
