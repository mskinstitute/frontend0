## 4. URL Inspection & Index Request Procedure

Follow this protocol in Google Search Console:

1. Copy canonical URL (e.g. `https://www.mskinstitute.in/courses/python-programming-masterclass`).
2. Paste into the top Search Console search bar: **"Inspect any URL in the current property"**.
3. Review the live inspection result:
   - **Coverage:** Is page indexed or discovered?
   - **User-declared canonical:** Must match `https://www.mskinstitute.in/courses/python-programming-masterclass`.
   - **Google-selected canonical:** Must agree with user canonical.
   - **Mobile Usability:** Must show "Page is usable on mobile".
   - **Rich Results:** Must display "Course", "Breadcrumbs", or "FAQPage" with green checkmarks.
4. Click **Request Indexing**.
5. Log inspection date in SEO records. Repeat for the top 15 priority URLs over a 5-day staggered window.
